# FinancialEmpire

一个基于 **PyQt5** 的单标的**多主体交易市场模拟器**。

20 个自动交易者在虚拟交易所中完整经历「**IPO 申购 → 摇号配售 → 二级市场连续竞价撮合**」的全过程，
界面以逐笔播放的方式实时展示**买卖盘深度**与**价格走势曲线**，用于观察微观结构下的价格形成机制。

---

## 功能特性

### 交易所（撮合核心）
- **交易者管理**：注册交易者并绑定交易所，统一维护资金、持仓、挂单。
- **IPO 发行**：设定发行价与发行总股数。
- **IPO 申购**：按发行价冻结申购资金，资金不足时自动缩量。
- **摇号配售**：完整实现打新算法 —— 统计认购倍数，申购不足则全额中签；超额则打乱顺序随机抽签，
  随后多轮补充分配直至分完（最多 10 轮，防死循环）；中签发股、未中签全额退款、冻结资金多退少补。
- **下单校验**：买单校验现金、卖单校验持仓，**禁止做空**。
- **资金/持仓冻结**：买单冻结现金，卖单冻结持仓，撤单时原路退回。
- **价格-时间优先撮合**：买价 ≥ 卖价即可成交，成交价取**先挂单方（order_id 较小）的报价**，
  同价按 **FIFO**；买方按价差退回多冻结的资金。
- **市场数据**：按价位聚合的多档盘口快照、最新成交价、完整成交流水。
- **诊断输出**：摆盘打印、交易所状态打印、全局汇总打印。

### 订单簿
- 双堆实现，插入 O(log n)：买盘用 `-price` 构造最大堆，卖盘最小堆，`order_id` 作第二排序键。
- 取最优价时惰性弹出已失效订单，快照输出「价位 + 该价位总量 + 各订单明细」。

### 交易者智能体
- **预期价格模型**：每隔随机 1–5 轮，在最新价 **±10%** 区间内重新生成预期价；
  仅当预期价**发生变化**时才触发交易决策，避免无意义下单。
- **决策规则**：
  | 持仓 | 观点 | 动作 |
  |---|---|---|
  | 无持仓 | 看涨（预期 > 最新价） | 按预期价下买单 |
  | 无持仓 | 看跌（预期 < 最新价） | 挂低价买单等待回调 |
  | 有持仓 | 看跌 | 按预期价下卖单 |
  | 有持仓 | 看涨 | 挂高价卖单等待拉升 |
- **挂单管理**：每个标的最多保留一张活跃挂单；价格或方向不一致时自动撤单重挂；
  下单数量按可用资金（含已冻结部分）或可用持仓计算。

### 图形界面（深色交易终端风格）
- **主窗口**：开始/继续、暂停、重置；1–8x 速度滑块；轮次进度、最新价（涨红跌绿）、成交笔数、最新成交明细。
- **摆盘视图**：自绘 8 档深度，卖盘在上、买盘在下，中间高亮最新价并显示**价差**与**较发行价涨跌**。
- **价格曲线**：自绘坐标轴与网格，刻度自适应；黄色虚线为 IPO 发行价基准；面积填充 + 播放头实时标示进度。
- 定时器 80ms 一帧，按速度倍率每帧推进多步；无变化的空步会被自动跳过，画面不会停顿。

### 日志
- 4 个级别（DEBUG / INFO / WARNING / ERROR），格式 `时间 | 级别 | 内容`。
- 内存缓存 500 条后批量落盘，支持强制刷盘（暂停、重置、关闭窗口时触发）。
- 日志文件位于 `Src/Logs/FELog_日期(时分秒).txt`。

拖动速度滑块可调整每个刷新周期推进的变化次数。

## 核心机制说明

### 撮合规则
1. 取买盘最高价与卖盘最低价，若**买价 < 卖价**则停止撮合。
2. 成交量为双方剩余量的较小值。
3. 成交价取**先挂单方**的报价（`order_id` 较小者视为被动方）。
4. 买方若出价高于成交价，差额部分退回其账户。
5. 更新最新成交价并生成成交记录，循环继续直到无法撮合。

### 下单与 IPO 的边界
- `Exchange.submit_order` 只处理**二级市场**的下单、校验、冻结与撮合，**不区分 IPO 阶段**。
- IPO 申购与配售一律走 `apply_ipo` / `allocate_ipo`，与二级市场链路互不干扰。
- `ipo_completed` 仅用于状态展示（`Exchange.print_status`），不参与任何下单校验。

### IPO 配售算法
1. 计算认购倍数 = 总申购量 / 发行总量。
2. **申购不足**：所有申购者全额中签。
3. **超额申购**：打乱申购顺序，依次随机抽取中签数量（上限与认购倍数负相关），
   任一环节剩余股数耗尽则后续申购者无法中签。
4. 若第一轮后仍有剩余，进入**补充分配**多轮循环，在仍有申购额度的人之间随机分配。
5. 结算：中签者获得股票并退还多余冻结资金，未中签者全额退款。

### 可调参数
集中在 `Src/Main/GUI/MarketSimulation.py`：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `NUM_TRADERS` | 20 | 交易者数量 |
| `SYMBOL` | `AAPL` | 交易标的 |
| `IPO_PRICE` | 100 | 发行价（整数） |
| `IPO_SHARES` | 10000 | 发行总股数 |
| `MAX_ROUNDS` | 100 | 模拟总轮次 |
| `BOOK_DEPTH` | 8 | 盘口档位深度 |

其余参数：初始资金服从对数正态分布（目标均值 10 万，截断于 1 万–1000 万）；
IPO 申购比例为可用资金的 50%–80%；价格全部使用**整数**，避免浮点精度问题。

## 已知行为约定与后续计划

**行为约定**
- `Exchange.submit_order` 不区分 IPO 阶段，IPO 申购/配售与二级市场撮合是两条独立链路。
- `ipo_completed` 目前仅用于状态展示（`Exchange.print_status`），不再参与下单校验。
- 预期价的更新间隔实际为 **1–5 轮**随机（`random.randint(1, 5)`）。
